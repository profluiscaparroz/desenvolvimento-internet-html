# 📂 Exemplos Introdutórios de HTML e CSS

## 📖 Sobre Esta Pasta

Esta pasta contém exemplos **introdutórios e didáticos** de HTML e CSS, criados durante as primeiras aulas do curso. São exemplos simples e diretos ao ponto, ideais para quem está dando os primeiros passos no desenvolvimento web.

> **Nota**: Estes exemplos complementam os módulos numerados do curso. Para uma aprendizagem estruturada e progressiva, siga os módulos numerados em ordem (`01-html-basico`, `02-html-estrutura-semantica`, etc.).

---

## 📋 Conteúdo dos Exemplos

| Arquivo | Conteúdo |
|---------|----------|
| **exemplo0.html** | DIV básica — conceito e uso do elemento `<div>` |
| **exemplo1.html** | DIV com CSS — estilização de containers com CSS inline e externo |
| **exemplo2.html** | Layout com Flexbox — alinhamento e distribuição de elementos |
| **exemplo3.html** | Exemplos de texto — headings, parágrafos e formatação |
| **exemplo4.html** | Links e imagens — tags `<a>` e `<img>` |
| **exemplo5.html** | Listas — listas ordenadas, não ordenadas e de definição |
| **exemplo6.html** | Tabelas — estrutura e estilização de tabelas HTML |
| **exemplo7.html** | Formulários — campos de entrada e botões |
| **exercicio.html** | Exercício prático — página com menu, tabela e lista combinados |

---

## 🎯 Como Usar

1. **Abra qualquer arquivo** diretamente no navegador
2. **Inspecione o código-fonte** no editor de texto (VS Code recomendado)
3. **Modifique os exemplos** e recarregue o navegador para ver as mudanças
4. **Use as ferramentas do desenvolvedor** (F12) para explorar a estrutura HTML e os estilos CSS aplicados
