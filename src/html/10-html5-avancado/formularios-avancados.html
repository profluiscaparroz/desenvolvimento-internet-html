Formulários com Bootstrap

O Bootstrap oferece classes e componentes prontos para criar formulários modernos e responsivos de forma rápida e eficiente.

Bootstrap 5: Utilizaremos o Bootstrap 5, que não depende de jQuery e oferece melhor performance.

Classes Bootstrap usadas:
• form-control: Estiliza inputs
• form-label: Estiliza labels
• mb-3: Margin-bottom (espaçamento)
• btn btn-primary: Botão estilizado

Classes de validação Bootstrap:
• needs-validation: Ativa validação HTML5
• valid-feedback: Mensagem de sucesso
• invalid-feedback: Mensagem de erro
• form-check: Container para checkboxes/radios
