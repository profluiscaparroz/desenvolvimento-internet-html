📚 HTML Básico - Portal de Exemplos Práticos

Bem-vindo ao módulo de HTML Básico!

Explore os elementos fundamentais do HTML através dos exemplos organizados abaixo. Cada página demonstra conceitos essenciais com exemplos práticos e código bem comentado.

💡 Dica: Abra o código-fonte de cada exemplo (botão direito → "Ver código-fonte da página") para entender como funciona!

🏗️ Estrutura e Fundamentos

  • 🆕 00 - Guia Completo da Estrutura HTML5 Básico

    Guia detalhado e didático sobre a estrutura completa HTML5: DOCTYPE, html, head, body, meta tags com explicações visuais e exemplos práticos.

  • 01 - Estrutura Básica HTML5 Básico

    Aprenda a estrutura completa de um documento HTML5: DOCTYPE, html, head, body e meta tags essenciais para responsividade.

  • 02 - Atributos HTML Básico

    Explore os atributos HTML mais comuns: id, class, style, title e como usá-los corretamente em seus elementos.

  • 03 - Tags Semânticas (header, nav, main, footer) Básico

    Entenda a importância das tags semânticas do HTML5 e como estruturar páginas de forma acessível e otimizada para SEO.

  • 04 - Divisões e Containers (div, span) Básico

    Aprenda a usar div e span para agrupar e organizar elementos, diferenciando containers de bloco e inline.

✍️ Texto e Formatação

  • 05 - Formatação de Texto Completa Básico

    Exemplo prático com títulos (h1-h6), parágrafos, ênfase, negrito, itálico, marcações e muito mais. Inclui história da Linguagem C como conteúdo de exemplo.

  • 06 - Estilização com CSS Interno Intermediário

    Veja como aplicar CSS interno (inline e na tag style) para estilizar elementos HTML e criar páginas visualmente atraentes.

🔗 Links e Navegação

  • 07 - Links e Seus Atributos Básico

    Domine a tag <a> e seus atributos: href, target, title, download. Aprenda sobre links externos, internos, âncoras e caminhos relativos/absolutos.

🖼️ Imagens e Mídia

  • 08 - Imagens e Atributos Básico

    Trabalhe com a tag <img>, atributos src e alt, dimensionamento, formatos de imagem e boas práticas de acessibilidade.

📋 Listas e Organização

  • 09 - Listas (ul, ol, dl) Básico

    Exemplo completo de listas não ordenadas, ordenadas e de definição. Inclui listas aninhadas e casos de uso práticos.

📊 Tabelas

  • 10 - Tabelas (table, thead, tbody, tr, td, th) Intermediário

    Crie tabelas estruturadas com cabeçalho, corpo e rodapé. Aprenda sobre mesclagem de células (colspan, rowspan) e tabelas acessíveis.

📝 Formulários

  • 11 - Formulários Básicos Básico

    Introdução aos formulários: tag <form>, inputs básicos (text, email, password), labels e botões de envio.

  • 12 - Tipos de Input e Validação Intermediário

    Explore todos os tipos de input HTML5: text, email, number, date, color, range, file e muito mais. Aprenda sobre validação de formulários.

📖 Dica de Estudo: Siga a ordem sugerida para melhor compreensão dos conceitos!
