📄 Estrutura Básica de um Documento HTML5

Bem-vindo! Este documento demonstra a estrutura básica e completa de uma página HTML5. Cada elemento está comentado e explicado para facilitar o aprendizado.

1. DOCTYPE - Declaração do Tipo de Documento

<!DOCTYPE html>

O <!DOCTYPE html> é a primeira linha de qualquer documento HTML5. Ele informa ao navegador que esta é uma página HTML5.

  • ✅ Deve ser a primeira linha do documento
  • ✅ Não é case-sensitive (pode ser maiúscula ou minúscula)
  • ✅ Sem ele, o navegador pode entrar em "quirks mode" (modo de compatibilidade)

2. Tag <html> - Elemento Raiz

<html lang="pt-BR">
    ...
</html>

A tag <html> é o elemento raiz que envolve todo o conteúdo da página.

  • lang="pt-BR": Define o idioma do documento (português brasileiro)
  • Importante para acessibilidade e SEO
  • Outros códigos comuns: en (inglês), es (espanhol), fr (francês)

3. Seção <head> - Metadados

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Título da Página</title>
</head>

O <head> contém metadados (informações sobre o documento) que não são exibidos na página.

Meta Tags Essenciais:

  • <meta charset="UTF-8">: Define a codificação de caracteres (suporta acentos e caracteres especiais)
  • <meta name="viewport"...>: Torna o site responsivo em dispositivos móveis
  • <meta name="description"...>: Descrição para mecanismos de busca
  • <meta name="keywords"...>: Palavras-chave relacionadas ao conteúdo
  • <title>: Título que aparece na aba do navegador

4. Seção <body> - Conteúdo Visível

<body>
    <h1>Título Principal</h1>
    <p>Parágrafo de texto...</p>
</body>

O <body> contém todo o conteúdo visível da página: textos, imagens, vídeos, formulários, etc.

5. Estrutura Semântica HTML5

<body>
    <header> ... </header> <!-- Cabeçalho -->
    <nav> ... </nav> <!-- Navegação -->
    <main>
        <section> ... </section> <!-- Seção -->
        <article> ... </article> <!-- Artigo -->
    </main>
    <aside> ... </aside> <!-- Conteúdo lateral -->
    <footer> ... </footer> <!-- Rodapé -->
</body>

HTML5 introduziu tags semânticas que dão significado ao conteúdo:

  • <header>: Cabeçalho da página ou seção
  • <nav>: Menu de navegação
  • <main>: Conteúdo principal (apenas 1 por página)
  • <section>: Seção temática do conteúdo
  • <article>: Conteúdo independente e reutilizável
  • <aside>: Conteúdo relacionado (sidebar)
  • <footer>: Rodapé da página ou seção

6. Exemplo Completo Mínimo

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Minha Página</title>
</head>
<body>
    <h1>Olá, Mundo!</h1>
    <p>Esta é minha primeira página HTML5.</p>
</body>
</html>

💡 Dica: Este é o mínimo necessário para uma página HTML5 válida. Use-o como template base para seus projetos!

7. Boas Práticas

✅ Faça:

  • Sempre inclua o DOCTYPE
  • Use o atributo lang na tag <html>
  • Sempre defina charset e viewport no <head>
  • Use indentação consistente (2 ou 4 espaços)
  • Feche todas as tags
  • Use tags semânticas quando apropriado
  • Adicione comentários explicativos

❌ Evite:

  • Esquecer o DOCTYPE
  • Não definir o charset (pode gerar problemas com acentos)
  • Usar apenas <div> quando existe tag semântica apropriada
  • Deixar tags abertas sem fechar
  • Escrever HTML sem indentação
