Cálculo do tamanho - content-box

Caixa Azul
(modelo padrão)

Propriedades:

  • width = 200px
  • padding = 20px (em cada lado)
  • border = 5px (em cada lado)
  • margin = 15px (em cada lado)

Cálculo da largura total:

200 (conteúdo)
+ 20 + 20 (padding)
+ 5 + 5   (bordas)
+ 15 + 15 (margens)
= 280px de largura total

Cálculo da altura: funciona da mesma forma.
