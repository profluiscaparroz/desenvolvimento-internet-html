Entendendo o CSS Box Model

O que é o Box Model?

No CSS, o "Box Model" é um conceito fundamental que define como os elementos HTML são renderizados. Cada elemento é representado como uma caixa retangular que consiste em:

  • Conteúdo (Content): A área onde o texto e imagens aparecem
  • Preenchimento (Padding): O espaço entre o conteúdo e a borda
  • Borda (Border): Uma linha que envolve o padding e o conteúdo
  • Margem (Margin): O espaço transparente fora da borda

Como calcular o tamanho total:

Largura total = width + padding-left + padding-right + border-left + border-right + margin-left + margin-right

Altura total = height + padding-top + padding-bottom + border-top + border-bottom + margin-top + margin-bottom
