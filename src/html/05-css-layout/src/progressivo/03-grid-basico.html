🔲 Passo 3: CSS Grid Básico

O que mudou: Agora usamos CSS Grid para criar o layout completo da página! Grid é perfeito para layouts bidimensionais (linhas E colunas).

Propriedades do Grid:

  • display: grid - Ativa o CSS Grid
  • grid-template-columns: 200px 1fr 200px - Define 3 colunas
  • grid-template-rows: auto 1fr auto - Define 3 linhas
  • grid-column: 1 / -1 - Elemento ocupa todas as colunas

📄 Conteúdo Principal

Agora estamos usando CSS Grid! Observe que todo o layout é controlado pelo grid do container pai.

O Código CSS do Grid:

.page-container { display: grid; min-height: 100vh; /* 3 colunas: 200px | flexível | 200px */ grid-template-columns: 200px 1fr 200px; /* 3 linhas: auto | flexível | auto */ grid-template-rows: auto 1fr auto; gap: 0.5rem; }

Fazendo Header e Footer Ocuparem 3 Colunas:

header { grid-column: 1 / -1; /* Coluna 1 até a última (-1) */ } footer { grid-column: 1 / -1; /* Mesma coisa */ }

Por Que Usar Grid Aqui?

  • ✅ Controle preciso de colunas e linhas
  • ✅ Layout bidimensional (linhas E colunas)
  • ✅ Fácil fazer elementos ocuparem múltiplas células
  • ✅ Código mais limpo e intuitivo
