📄 Conteúdo Principal

Este é o conteúdo principal da página. Aqui vai todo o texto, imagens e informações relevantes.

Observe que sem CSS de layout (Flexbox ou Grid), todos os elementos aparecem em sequência vertical, seguindo o fluxo normal do documento HTML.

Problemas do Layout sem CSS:

  • Elementos sempre um embaixo do outro
  • Difícil criar layouts em colunas
  • Impossível alinhar elementos lado a lado facilmente
  • Não responsivo automaticamente
