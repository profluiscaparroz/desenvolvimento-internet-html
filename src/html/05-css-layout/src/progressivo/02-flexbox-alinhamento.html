🎯 Passo 2: Flexbox para Alinhamento e Layout

O que mudou: Agora usamos Flexbox para criar um layout de duas colunas (main e aside lado a lado) e centralizamos o conteúdo do footer!

Novas propriedades:

  • flex: 1 - Elemento cresce para ocupar espaço disponível
  • flex: 0 0 250px - Largura fixa de 250px, não cresce nem encolhe
  • flex-direction: column - Organiza itens em coluna vertical

📄 Conteúdo Principal

Agora o conteúdo principal e a barra lateral estão lado a lado! Isso foi feito com Flexbox aplicado ao container pai.

O Código CSS Aplicado:

.content-container { display: flex; gap: 1rem; } main { flex: 1; /* Ocupa todo o espaço disponível */ } aside { flex: 0 0 250px; /* Largura fixa de 250px */ }

Entendendo flex: 1 vs flex: 0 0 250px

flex: 1

Cresce para ocupar espaço disponível

flex: 0 0 200px

Largura fixa (este box)

Footer Centralizado:

footer { display: flex; flex-direction: column; /* Itens em coluna */ align-items: center; /* Centraliza horizontalmente */ justify-content: center; /* Centraliza verticalmente */ }
