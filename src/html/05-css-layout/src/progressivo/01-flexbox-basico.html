📄 Conteúdo Principal

Observe como o header agora tem elementos alinhados horizontalmente! O logo à esquerda e as informações do usuário à direita.

O Código CSS Aplicado:

header { display: flex; justify-content: space-between; align-items: center; padding: 1.5rem 2rem; } nav ul { display: flex; gap: 2rem; list-style: none; }

Por Que Isso Funciona:

  • display: flex - Transforma o container em flex container
  • justify-content: space-between - Logo vai para esquerda, usuário para direita
  • align-items: center - Alinha tudo verticalmente ao centro
  • gap - Espaçamento uniforme entre itens de navegação
