📄 Grid Template Areas

Esta é a forma mais intuitiva de criar layouts com CSS Grid! Você nomeia as áreas e depois posiciona os elementos nessas áreas.

🎯 O Código CSS com Grid Areas:

.page-container { display: grid; grid-template-columns: 200px 1fr 200px; grid-template-rows: auto 1fr auto; /* ✨ Áreas nomeadas - Visual! */ grid-template-areas: "header header header" "nav main aside" "footer footer footer"; } /* Posicionando elementos */ header { grid-area: header; } nav { grid-area: nav; } main { grid-area: main; } aside { grid-area: aside; } footer { grid-area: footer; }

📐 Visualização das Áreas:

┌─────────────────────────────────┐ │ header header header │ ← Ocupa 3 colunas ├─────────┬───────────┬───────────┤ │ nav │ main │ aside │ ← Cada um em 1 coluna ├─────────┴───────────┴───────────┤ │ footer footer footer │ ← Ocupa 3 colunas └─────────────────────────────────┘

🌟 Vantagens do Grid Areas:

  • ✅ Visual: O código CSS "desenha" o layout
  • ✅ Intuitivo: Fácil de entender e manter
  • ✅ Flexível: Fácil reorganizar em diferentes telas
  • ✅ Semântico: Nomes descritivos (header, main, etc)

🔄 Comparação: Grid Column vs Grid Areas

/* Método 1: Com grid-column (menos intuitivo) */ header { grid-column: 1 / -1; /* O que isso significa? */ grid-row: 1; } /* Método 2: Com grid-area (mais claro!) */ header { grid-area: header; /* Claro e descritivo! */ }

💡 Dica Profissional:

Use Grid Areas sempre que possível! É mais fácil de ler, entender e manter. Outros desenvolvedores (ou você mesmo no futuro) vão agradecer!
